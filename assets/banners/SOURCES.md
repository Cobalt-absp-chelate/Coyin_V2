# Banner Reference Notes

The current built-in banner presets are shipped as original layered SVG scenes in this repository.
No third-party character art or copyrighted anime stills are distributed in the default assets.

The following public pages were used as visual reference points while reworking the scene composition:

## Night city / cyber city references

- Pixabay illustration listing:
  https://pixabay.com/illustrations/city-night-landscape-anime-urban-9330382/
  License note: Pixabay content page, reference only. Final shipped preset is an original SVG redraw.

- Public Domain Pictures listing:
  https://www.publicdomainpictures.net/en/view-image.php?image=511609&picture=anime-city
  License note: page indicates CC0 / public domain. Used only as a loose scene reference; final asset is not a direct copy.

## Sunset / warm study scene references

- Pixabay anime sunset search result used as mood reference:
  https://pixabay.com/illustrations/sunset-anime-minimal-nature-sky-7628294/
  License note: Pixabay content page, reference only. Final shipped preset is an original SVG redraw.

- General panoramic composition reference search:
  https://pixabay.com/images/search/anime%20cityscape/
  License note: Pixabay search page, reference only.

## User custom layers

Users can upload their own local `background`, `midground`, `foreground`, and `overlay` images.
Those custom layers are stored only on the local machine under the runtime banner directory and are not bundled into the public default assets.
